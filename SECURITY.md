# Security reports

Please use GitHub's **Report a vulnerability** link on this repository's Security tab when it is available. If private reporting is not enabled, open an issue asking the maintainer for a private contact route without including vulnerability details.

Do not post API tokens, account IDs, request headers, Worker logs, or other account data in public issues. If a credential may have been exposed, revoke or rotate it in Cloudflare before sharing a report.

Only the current `0.1.x` Windows alpha is being maintained. macOS has not been tested or released.
